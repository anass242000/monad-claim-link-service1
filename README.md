Overview: The Claimable Token Link Service enables users to create claimable links for token transfers, allowing recipients to easily claim tokens. The service provides an intuitive web interface and integrates with Ethereum-compatible blockchains, such as Monad, and ERC20 tokens (e.g., CHOG, DAK, YAKI). It handles both the creation of claim links and the claiming process, ensuring a secure, easy-to-use experience for both the sender and the receiver.

Key Features:
Wallet Integration:

Connect Wallet: Users can connect their Ethereum-compatible wallet (e.g., MetaMask) using ethers.js. Once connected, the wallet address is displayed on the UI, and the user is presented with options to create or claim links.

Create Claim Links:

Token Selection: The user can select the token they want to send from a dropdown (e.g., CHOG, DAK, YAKI) or choose the native token (MONAD) for the transfer.

Amount & Expiry: The sender enters the amount of tokens to send and specifies the expiration time (in hours) for the claim link.

Service Fee: A fixed fee of 0.2 MONAD is applied to create the claim link (paid in the native MONAD token).

Transaction Flow:

For Native Token (MONAD): No approval is required as MONAD is directly sent to the contract via a payable transaction.

For ERC20 Tokens: The sender must approve the contract to spend the specified token amount before creating the claim link.

Claim Link Creation: Once the transaction is confirmed, the system generates a claim link. The claim ID (unique identifier) is returned, and the details (amount, token, expiry) are displayed on the page.

Claim Tokens:

Claim Link: The recipient can access a claim link (shared by the sender) to claim their tokens.

Claim Information: The claim page auto-fetches the claim details (e.g., token type, amount, expiry, creator's address) using the claim ID.

Claim Process: Upon clicking the claim button, the recipient’s wallet must approve the transaction to claim the tokens. The transaction is processed via the claim() function in the smart contract.

Success Message: After the transaction is confirmed, the recipient receives a success message indicating that the tokens have been successfully claimed.

Flow of the Application:
Wallet Connection:

The user connects their wallet using MetaMask (or another Ethereum-compatible wallet). The wallet address is shown on the page, and the UI updates to allow interaction with the claim link creation and claiming processes.

Creating the Claim Link:

Token Selection: The sender selects a token from the dropdown list (CHOG, DAK, YAKI, or MONAD).

Token Amount: The sender specifies the amount of tokens to send.

Expiry Time: The sender sets the expiry time for the claim link.

Transaction Approval: If the selected token is an ERC20 token (other than MONAD), the sender must first approve the contract to spend the token. For MONAD (native token), no approval is needed, and the transfer is done via a simple payable transaction.

Claim Link Creation: Upon confirming the transaction, the system generates a unique claim ID and displays it with all relevant information (e.g., token type, amount, expiration, and sender's address).

Claiming Tokens:

The recipient clicks the claim link provided by the sender.

The claim page fetches the claim details by using the claim ID and displays:

Token Address (name or symbol if available).

Amount to be Claimed.

Creator's Address (the address that created the claim link).

Expiration Time (when the link will expire).

The recipient approves the transaction to claim the tokens. After the claim is successfully processed, a success message is displayed.

Smart Contract Flow:
createClaimLink():

Input parameters:

token: The address of the ERC20 token or 0 for the native token (MONAD).

amount: The amount of tokens to be sent.

expireTime: The expiration timestamp (in seconds) of the claim link.

claimId: A unique identifier for the claim link (generated by hashing the current time).

Fee: The sender must also pay a service fee of 0.2 MONAD when creating the claim link.

claim():

Input parameters:

claimId: The unique ID of the claim link.

This function allows the recipient to claim the tokens linked to the provided claim ID.

Technical Details:
Frontend:

Wallet Integration: The app uses ethers.js to interact with Ethereum-compatible wallets (e.g., MetaMask).

UI Components: The web interface includes forms for:

Connecting the wallet.

Selecting the token and entering the claim details.

Entering the claim ID to claim tokens.

Dynamic Information: Upon opening a claim link, the page automatically fetches the relevant details about the claim (token, amount, expiration) and displays them to the recipient.

Backend:

Smart Contract: The smart contract is deployed on the Monad testnet, allowing users to create claim links and claim tokens based on those links.

Claim Validation: The contract validates if the claim link exists, if the recipient is eligible, and whether the claim has expired.

User Experience (UX) Design:
For the Sender (Creator of Claim Link):

Connect wallet and choose token (ERC20 or MONAD).

Input the amount of tokens and expiry time.

Approve the transaction (if needed) and confirm the claim link creation.

Receive a claim link with details to share.

For the Recipient (Claiming Tokens):

Open the claim link.

View details of the claim, including token, amount, expiration, and creator's address.

Approve the transaction to claim tokens.

Receive confirmation of successful claim.

Benefits:
Simplicity: The process is easy for both senders and recipients, involving minimal steps for creating and claiming tokens.

Flexibility: Supports both native tokens (MONAD) and ERC20 tokens.

Security: All token transfers and claims are processed securely via smart contract interactions.

Transparency: The claim details are clearly displayed for both parties (sender and receiver), including the expiration time and token information.
